# RD-Aspen RAS Handler Service module
The RD-Aspen RAS Handler Service module is responsible for setting up
the Reliability, Availability, and Serviceability (RAS) infrastructure
in RD-Aspen’s RAS-enabled IP blocks. It abstracts hardware details such
as interrupt routing and error-record register addresses, so that
different IP types (e.g., CPU clusters, CMN, SMMU, MHU etc) can share a
common initialization path.

# Descriptor for configuring and registering the RAS ISR for a given IP

The `mod_ras_isr_desc` structure encapsulates all the information needed
to register and handle a Reliability, Availability, and Serviceability
(RAS) interrupt for an RD-Aspen RAS-capable IP block. It specifies the
interrupt vector and trigger type, identifies the IP instance, and
provides pointers to any per-PE and error-record bases required for
proper error handling.
Members:

- **interrupt_no**
  The hardware interrupt vector number assigned to this RAS IP. This
  must match the interrupt controller (e.g., GIC) configuration.

- **interrupt_trigger_type**
  The interrupt trigger scheme (level- or edge-triggered). Format is
  implementation-defined but typically uses the same encoding as the
  platform’s IRQ controller (e.g., level-low, edge-rising).

- **ip_type**
  Enumerated RAS IP type (`enum ras_ip_type`) indicating which RAS
  block is being serviced (e.g., `RAS_IP_TYPE_CPU`, `RAS_IP_TYPE_CLUSTER`).

- **pe_ids**
  Optional pointer to an array of PE (Processing Element) IDs for
  CPU-based RAS. If the RAS IP requires per-PE error-record
  configuration (e.g., multi-core CPUs), this array lists each PE
  index. Pass `NULL` if the IP does not need per-PE IDs.

- **pe_count**
  Number of entries in the `pe_ids` array. Applies only to CPU IPs.
  Must be 0 if `pe_ids == NULL`.

- **err_records_base**
  Pointer to an array of base addresses (type `uintptr_t`) for each
  Error Record Register.

- **mhu_in_base**
  Base address of the MHU receiver register set for inbound
  synchronization from the AP to this RAS block. Used to acknowledge
  or receive RAS interrupts generated by this IP at the AP side.

- **mhu_out_base**
  Base address of the MHU sender register set for outbound
  synchronization to the AP. Writing to these registers signals the AP
  that a RAS event has occurred in this block.

- **mhu_channel**
  The MHU channel index used for synchronization. Each channel
  corresponds to a specific doorbell or FIFO in the MHU block.

- **mhu_flag**
  Bit-flag within the MHU status register used to detect or clear
  synchronization events. The MHU driver uses this flag to poll for
  completion.

- **mhu_poll_retries**
  Maximum retry count when polling the MHU status register for the
  `mhu_flag`. If the flag does not clear within this many attempts,
  the sync operation fails.
For IPs that expose multiple error-record banks (e.g., one per PE),
list each base here. For single-bank IPs, provide a single-element array.
- **err_record_count**
  Number of entries in the `err_records_base` array. Must match the
  number of valid error “banks” to be programmed.
